## How to use the copy

Only the text between `<!-- public-copy:start -->` and `<!-- public-copy:end -->` is intended for the website. Route, layout, source, and publication notes are editorial instructions. Keep those out of rendered pages and public metadata.

All public copy is a draft for Aaditya's factual and voice review. Source documents establish project scope but do not establish individual ownership of every implementation decision. The case studies therefore describe the work without claiming sole authorship.

No email address, degree, graduation year, current employer, availability, portrait, publication, or client testimonial has been invented. Missing information has an explicit omission rule so the website can be built without broken buttons or visible placeholders.

That file describes a different person, and none of its identity, employment, or projects appears in the copy.
